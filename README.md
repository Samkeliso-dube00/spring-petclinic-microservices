# Spring PetClinic Microservices: DevOps & Cloud Engineering Portfolio

An independent engineering portfolio documenting the practical application of DevOps, containerisation, orchestration, automation and cloud deployment using the open-source [Spring PetClinic Microservices](https://github.com/spring-petclinic/spring-petclinic-microservices) application.

> **Project ownership:** This repository contains independent DevOps engineering documentation, configuration analysis, implementation work and supporting evidence. It is not the original Spring PetClinic application source code. The upstream application and its contributors retain their original ownership and attribution.

**Project tracking:** [Jira-board - Spring PetClinic](https://lainnecoatzee-1792906024509.atlassian.net/jira/software/projects/SPC/boards/35/backlog?epics=visible&jql=parent%20%3D%20SPC-1).

---

## Why Spring PetClinic Microservices?

I selected Spring PetClinic Microservices because it provides a realistic distributed Java application for exploring the engineering challenges involved in deploying and operating microservices.

The project provides practical exposure to:

- **Distributed Architecture:** Spring Cloud Config Server, Eureka Service Discovery and API Gateway.
- **Observability:** Prometheus, Grafana, Micrometer and Zipkin.
- **Containerisation:** Docker images, Dockerfiles and multi-container deployment with Docker Compose.
- **Orchestration:** Kubernetes deployment using Kind.
- **Cloud and Infrastructure:** AWS architecture, Terraform and automated deployment workflows.

## 🗺️ Engineering Roadmap

### Stage 1: Local Engineering & Deployment: In Progress

- Application discovery and architecture analysis.
- Ubuntu environment preparation and tooling validation.
- Native local application deployment using Java and Maven.
- Docker image and Dockerfile analysis.
- Docker Compose deployment and verification.
- Local Kubernetes orchestration using Kind.
- CI/CD and security foundations.
- Monitoring and operational readiness.

### Stage 2: AWS Cloud Deployment: Planned

- AWS architecture evaluation and cost planning.
- Infrastructure provisioning using Terraform where appropriate.
- Amazon ECR and container image management.
- Application deployment on a suitable AWS runtime.
- Networking, IAM and security controls.
- GitHub Actions cloud deployment pipelines.
- Cloud monitoring and operational management.

> *Implementation progress is tracked through Jira acceptance criteria and supported by verified technical evidence.*
